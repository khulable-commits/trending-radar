# Trending projects and models profile

Use this profile for entries that come from a live trending ranking rather than from a dated publication: GitHub Trending repositories and Hugging Face trending models.

Typical items are a repository or model that is gaining stars, likes, downloads, or usage right now. The value is in knowing what developers are adopting this week and why it is spreading, not in a neutral description of the project.

Do not use this profile for ordinary news articles, opinion pieces, tutorials, or release notes that are not part of a trending ranking.
